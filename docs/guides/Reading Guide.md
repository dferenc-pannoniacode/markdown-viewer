## Work with folders

Open a folder in the library to see its documents. Links between files are resolved within the active library.

| Link type | Example |
| --- | --- |
| Relative link | `[Welcome](../README.md)` |
| Wiki link | `[[README]]` |
| Link to a heading | `[[Reading Guide#Change the theme]]` |

## Change the theme

Choose **System**, **Light**, or **Dark** from the toolbar. The viewer remembers your selection in this browser.
