# Markdown Viewer

Browse and read a folder of Markdown files. Use the library on the left to open a document, or follow the links as you read.

## Try a link

- [Open the reading guide](guides/Reading%20Guide.md)
- [Jump to a heading](guides/Reading%20Guide.md#work-with-folders)
- [[Reading Guide#Change the theme|Jump using a wiki link]]

## Open your own documents

**Mounted** shows the folder attached to the Docker container. Use **Open folder** to read a folder from this device.

> Files chosen in the browser stay on this device. To reopen a bookmarked local document after a reload, select the same folder again.
